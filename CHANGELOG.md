# Changelog

All notable changes to Snapdown are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and Snapdown adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Screen capture of a region, a window, or the full screen, with a magnifier loupe for precise selection.
- Annotation tools: numbered markers, arrows, callouts, text notes, and blur for hiding sensitive content.
- Markdown export: one file with the annotated image and numbered notes that match its markers, ready to hand to a colleague or paste into a coding agent conversation.
- PDF export of a Bundle of Findings.
- Size reduction for PNG and WebP images, preserving aspect ratio.
- A local library of Findings and Bundles, stored on your own computer.
- System tray integration and customisable global hotkeys.
- Installer (`Snapdown-Setup.exe`), portable executable (`Snapdown-Portable.exe`), and a Scoop bucket.
- Update check that verifies each installer's SHA-256 checksum before running it; it can be switched off in Settings.
- Licence terms, privacy policy, and security policy, covering Snapdown and Snapdown Pro, the optional one-time licence that removes the attribution mark from exported PDFs.
