# Scoop bucket

This folder holds the Scoop manifest for Snapdown. To install:

```
scoop bucket add snapdown https://github.com/wiradeltaid/snapdown-releases
scoop install snapdown
```

`snapdown.json` is generated by the release process from the published files, so its version,
download URL, and hash always match the release they describe. If the manifest gives you trouble,
please open an issue rather than editing it.
